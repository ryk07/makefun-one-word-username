# One Word, One Username

Entry for the make.fun bounty [One Word, One Username, One Reward](https://make.fun/c/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

The program writes the entrant's own make.fun username — one word and
nothing else — to `/output/entry.txt`. No explanation, no links, no pitch.

Run it:

```sh
python3 main.py
```
